# Unity - 360 Video Tour

## Description
A VR experience that allows users to navigate through four 360-degree environments from Holberton School.

## Video Sources
- LivingRoom.mp4
- Cantina.mp4
- Cube.mp4
- Mezzanine.mp4

## Features
- Interactive hotspots to move between rooms
- Fade-in/out transitions for comfort
- Informational panels per room
- Background music with audio mixer
